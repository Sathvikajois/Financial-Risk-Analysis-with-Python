# Financial Risk Analysis with Python

## 📌 Project Overview
This project analyzes financial transaction data to identify customer behavior patterns and potential financial risk indicators using Python. It explores transaction trends, account performance, overdrafts, and balance volatility through data analysis and visualization.

## 🎯 Objectives
- Identify potential financial risk indicators.
- Analyze customer transaction patterns and account performance.
- Detect anomalies and explore unusual financial trends.
- Present insights through data visualizations.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Statistical Analysis
- Hypothesis Testing
- Anomaly Detection
- Data Visualization

## 🔍 Key Analysis
- Data cleaning and preprocessing
- Customer segmentation
- Hypothesis testing
- Anomaly detection
- Exploratory data analysis and visualization
